## Microsoft Clarity

Microsoft Clarity gives product teams heatmaps and session recordings. This project adds an automated layer on top: it flags manipulative UI patterns, known as dark patterns, in the behavioral data teams already collect, and supports more ethical user experiences.

## About this project

An academic team project at the University of Haifa. We worked together across research, design, data analysis and presentation. [TODO: one sentence on how work was split and which part was mine]

## The problem

Optimizing on behavioral data can push teams toward experiences that exploit users' emotional or cognitive patterns, often unintentionally.

## The goal

Detect dark patterns early, at the analysis and decision stage, and reduce users' exposure to manipulative experiences.

## The solution

A new feature in Clarity that detects potential dark patterns using existing behavioral data, and surfaces clear indicators that help analysts evaluate design decisions from both a performance and an ethical perspective.

## Research insights

Through interviews with UX practitioners and analysis of industry workflows, we found that teams rely heavily on behavioral data, such as session recordings and interaction patterns, to identify usability issues.

However, investigating frustration signals like rage clicks, repeated interactions and abandoned flows is often manual, time-consuming and fragmented across tools.

This revealed an opportunity to centralize and automate dark pattern detection within Microsoft Clarity, turning raw behavioral data into actionable insights.

## Widget evolution

This section presents the design journey of the widget, showing how research, usability insights and iteration refined the experience over time.

<Iteration>
  <IterationStage
    title="Initial Integration"
    video="dark-pattern-detection/iteration-1-ethical-insights"
    alt="Version 1: the Clarity dashboard with an Ethical Insights tab showing Total Ethical Flags 286, Average Ethical Score 52%, Critical Criteria 3 and Transparency Index 44%."
  >
    We introduced the widget inside an existing dashboard tab under the name Ethical Insights, creating initial visibility into site ethics. It showed the number of detected dark patterns, an overall score and a severity breakdown. A dedicated internal page expanded the data with graphs and deeper analysis.
  </IterationStage>
  <IterationStage
    title="Dedicated Experience"
    video="dark-pattern-detection/iteration-2-dp-detect"
    alt="Version 2: the Clarity dashboard with a DP Detect widget listing Leaving cart, CTA rejection, Flow break, Newsletter skip and Leaving form."
  >
    Recognizing the need for a stronger presence, we moved the widget to its own tab and renamed it DP Detect. The dashboard highlighted user actions triggered by dark patterns and detection counts per location.

    A dedicated internal page explained the severity logic, included AI insights and listed all patterns, each with recordings and heatmaps for deeper investigation.
  </IterationStage>
  <IterationStage
    title="Centralized Dashboard"
    video="dark-pattern-detection/iteration-3-centralized"
    alt="Version 3: a single Dark Patterns widget with 14 total and 6 critical dark patterns, a three-level severity bar, and the patterns sorted by most critical."
  >
    To reduce fragmentation and navigation friction, we removed the internal page, renamed the widget Dark Patterns and centralized all data in the dashboard.

    Users could view all detections, identify critical cases, sort by severity and open contextual recordings and heatmaps, supported by a clear severity visualization.
  </IterationStage>
  <IterationStage
    title="Session Impact Focus"
    video="dark-pattern-detection/iteration-4-session-impact"
    alt="Version 4: the Dark Patterns widget with 1,960 affected sessions, a checkbox per pattern, and an affected-sessions-over-time line chart with one line per pattern."
  >
    In the final iteration, we shifted from detection to measuring real impact. Each dark pattern showed its number of affected sessions, with advanced filtering and comparison tools.

    Recordings highlighted the exact moment of impact, and a graph showed session impact over time, connecting behavioral detection to actionable business insight.
  </IterationStage>
</Iteration>
